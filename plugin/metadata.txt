about=Copla exposes a small, well-defined JSON API on 127.0.0.1 that an MCP server (copla) uses to drive QGIS: manage layers, query features, run Processing algorithms, render maps and manage projects. Every operation is a typed tool with validated parameters - there is NO execute-arbitrary-Python endpoint. Auth is by random token stored in your profile; the server binds to localhost only and refuses browser (Origin) requests. Pair it with the copla MCP package for Claude, opencode, Cursor, VS Code, etc. The dock panel shows a ready-to-paste config snippet for each client (one-click setup) and includes an embedded chat tab with an opencode-style agent selector (Copla, Explorador, Cartografo, Editor, Descargas, General): use any OpenAI-compatible provider with one-click free presets (MiMo v2.5 Free via OpenCode Zen, OpenRouter free, Groq free, Google Gemini free, Ollama, LM Studio...) for streaming conversation with tool-calling over the same typed tools, persistent history and an editable system prompt. Created by Daniel Malan with opencode.
